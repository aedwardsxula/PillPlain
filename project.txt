Steps to hide API key
1) Never upload API directly to GitHub
2) Store the development API key within local.properties
3) Verify local.properties is included in .gitignore
4) Verify buildFeatures {
buildConfig = true in the build.gradle.kts
5) Configure Gradle to read API key from local.properties
6) Don’t print the API key within Logcat
7) Remove/Replace any exposed API key
